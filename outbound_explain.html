อธิบายโค้ดหน้า "เบิกจ่ายสินค้า" ทีละส่วน — สำหรับผู้เริ่มต้น

1. Import — นำเข้าเครื่องมือที่ต้องใช้
import React, { useState, useCallback } from 'react'; import { View, ScrollView, StyleSheet, Alert } from 'react-native'; import { Text, Button, TextInput, Card } from 'react-native-paper'; import { Picker } from '@react-native-picker/picker'; import Icon from 'react-native-vector-icons/MaterialCommunityIcons'; import { useFocusEffect } from '@react-navigation/native'; import Toast from 'react-native-toast-message'; import DatabaseService from '../db/DatabaseService'; import { Product, StockEntry, TransactionLog } from '../types';
💡 อธิบาย:

import = "ยืมเครื่องมือมาใช้" เหมือนเปิดกล่องเครื่องมือแล้วหยิบอันที่ต้องใช้

• useState — สร้างตัวแปรที่เปลี่ยนค่าได้ (เมื่อเปลี่ยน หน้าจอจะ update)

• useCallback — สร้าง function ที่จำค่าไว้ ไม่สร้างใหม่ทุกรอบ

• View, ScrollView — กล่องใส่ของ (เหมือน div ใน HTML)

• Alert — กล่อง popup ถามยืนยัน

• Picker — dropdown เลือกค่า

• Toast — ข้อความแจ้งเตือนที่โผล่มาแปปแล้วหาย

• DatabaseService — ตัวจัดการฐานข้อมูล

🎮 เปรียบเทียบ:

เหมือนก่อนทำอาหาร ต้องหยิบเครื่องมือมาวางบนโต๊ะก่อน — มีด, กระทะ, ถ้วย ฯลฯ

2. State — ตัวแปรที่หน้าจอจำไว้
const [products, setProducts] = useState<Product[]>([]); const [selectedProduct, setSelectedProduct] = useState<number>(0); const [productStock, setProductStock] = useState<StockEntry[]>([]); const [quantity, setQuantity] = useState(''); const [recentLogs, setRecentLogs] = useState<...>([]); const [lastOutboundSummary, setLastOutboundSummary] = useState(null);
💡 อธิบาย:

useState สร้างตัวแปร 2 ตัว: [ค่า, ฟังก์ชันเปลี่ยนค่า]

• products — รายชื่อสินค้าทั้งหมด

• selectedProduct — สินค้าที่ผู้ใช้เลือกอยู่ (เก็บ id)

• productStock — สต็อกของสินค้าที่เลือก (อยู่โซนไหน กี่ชิ้น)

• quantity — จำนวนที่ผู้ใช้พิมพ์

• recentLogs — ประวัติเบิกจ่ายล่าสุด

• lastOutboundSummary — สรุปการเบิกครั้งล่าสุด

🎮 เปรียบเทียบ:

เหมือนกระดาษโน้ตที่แปะอยู่หน้าจอ — เขียนค่าไว้ ลบแล้วเขียนใหม่ได้ ทุกครั้งที่เขียนใหม่ หน้าจอจะ refresh

3. loadData — โหลดข้อมูลจาก Database
const loadData = useCallback(async () => { const db = DatabaseService.getInstance(); const prods = await db.getAllProducts(); setProducts(prods); // ... โหลด logs ด้วย }, []); useFocusEffect(useCallback(() => { loadData(); }, [loadData]));
💡 อธิบาย:

• async/await — บอกว่า "รอให้เสร็จก่อนค่อยทำบรรทัดต่อไป" (เพราะอ่าน DB ใช้เวลา)

• DatabaseService.getInstance() — เอาตัวจัดการ DB มาใช้

• getAllProducts() — ดึงสินค้าทั้งหมดจาก DB

• setProducts(prods) — เอาข้อมูลที่ได้ไปเก็บใน state

• useFocusEffect — "ทุกครั้งที่กลับมาหน้านี้ ให้โหลดข้อมูลใหม่"

🎮 เปรียบเทียบ:

เหมือนเปิดสมุดคลัง ทุกครั้งที่เดินมาถึงหน้าเคาน์เตอร์ → เปิดดูว่ามีสินค้าอะไรบ้าง

= ตรวจสอบข้อมูลก่อนทำจริง ถ้าผิดก็บอก error แล้ว return (หยุด ไม่ทำต่อ)

// ขั้นที่ 4: คำนวณแผนการเบิก const sorted = [...productStock].sort((a, b) => b.quantity - a.quantity); let remaining = qty; const plan = []; for (const s of sorted) { if (remaining <= 0) break; // เบิกครบแล้ว หยุด const take = Math.min(remaining, s.quantity); // เอาเท่าที่มีหรือเท่าที่ต้องการ plan.push({ zone: s.zone, qty: take, ... }); remaining -= take; // ลดจำนวนที่ยังต้องเบิกอีก }
💡 อธิบาย Algorithm:

1. sort — เรียงโซนจากมีของมากสุดไปน้อยสุด

2. remaining — จำนวนที่ "ยังต้องเบิกอีก" เริ่มต้น = จำนวนที่ต้องการทั้งหมด

3. วน loop ทีละโซน: เอาเท่าที่มี หรือเท่าที่ยังขาด (อันไหนน้อยกว่า)

4. ลด remaining ลง → ถ้า remaining = 0 แปลว่าครบแล้ว หยุด

💡 JSX คืออะไร?

= "HTML ของ React" — เขียน UI ด้วยภาษาคล้าย HTML แต่อยู่ใน JavaScript

• <View> = กล่อง (เหมือน <div>)

• <Text> = ข้อความ (เหมือน <p>)

• <Card> = การ์ดมีเงา (จาก react-native-paper)

• {...} = ใส่ค่า JavaScript เข้าไปใน UI

• {condition && <Component/>} = แสดง component เมื่อ condition เป็น true
